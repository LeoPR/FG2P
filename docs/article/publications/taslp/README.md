# IEEE/ACM TASLP — Submission Guide

**Venue**: IEEE/ACM Transactions on Audio, Speech, and Language Processing
**Tipo**: Journal (top-tier, rolling submissions)
**Deadline**: Nenhuma — submissao continua
**Impact Factor**: ~4.1 (2024)
**Turnaround**: 3-6 meses para primeira decisao
**Site**: https://signalprocessingsociety.org/publications-resources/ieeeacm-transactions-audio-speech-and-language-processing

---

## Especificacoes

| Item | Valor |
|------|-------|
| Template | IEEEtran transactions (2 colunas) |
| Paginas | 10-14 paginas (tipico para artigo regular) |
| Lingua | Ingles |
| Review | Single-blind (autor visivel, revisor anonimo) |
| Submission | PDF via ScholarOne / Manuscript Central |

## Processo de Submissao

1. **Preparar manuscrito**: Compilar no formato IEEEtran transactions. 10-14 paginas tipico.
2. **Incluir autores**: Single-blind — nomes, afiliacoes e link para repositorio podem constar.
3. **Preparar cover letter**: Explicar contribuicao, relacao com versoes de conferencia (se houver), e o que e novo.
4. **Criar conta no ScholarOne**: Acessar Manuscript Central, selecionar TASLP.
5. **Upload**: Submeter PDF + cover letter + arquivos suplementares (codigo, dados).
6. **Revisao**: 3-6 meses. Decisoes possiveis: accept, minor revision, major revision, reject.
7. **Revisao (se solicitada)**: Submeter versao revisada com response letter detalhando cada mudanca.

## Requisitos Especificos para Versao Expandida de Conferencia

TASLP aceita versoes expandidas de artigos de conferencia (ICASSP, SLT, INTERSPEECH):
- Pelo menos **30% de conteudo novo**
- **Citar a versao de conferencia** explicitamente
- **Declarar** na cover letter o que e novo vs. o que vem da conferencia

## Politica de IA (IEEE)

Mesma politica IEEE aplicavel a journals:

> "The use of content generated by AI in an article shall be disclosed in the acknowledgments section. The AI system used shall be identified."

**Isencao**: Edicao e gramatica sao isentas de disclosure obrigatorio.

**Proibicao**: IA nao pode ser listada como autor. Autores assumem total responsabilidade.

Fonte: [IEEE Author Center](https://journals.ieeeauthorcenter.ieee.org/become-an-ieee-journal-author/publishing-ethics/guidelines-and-policies/submission-and-peer-review-policies/)
