## Processo de Submissao

1. **Preparar PDF**: Compilar no template ISCA. Regular: 4+1. Long paper: verificar limites do CFP 2027.
2. **Anonimizar**: Remover nomes, afiliacoes, links para repositorio.
3. **Submeter via ISCA platform**: Upload do PDF, preencher metadados, selecionar area tematica.
4. **Aguardar revisao**: Notificacao ~maio/junho 2027.
5. **Camera-ready**: Se aceito, submeter versao final com autores e afiliacoes.
6. **Apresentacao**: Oral ou poster conforme designacao.

## Anonimizacao (double-blind)

- Remover nomes e afiliacoes
- Nao referenciar repositorio GitHub
- Usar linguagem neutra para trabalho proprio

## Politica de IA (ISCA)

> "Authors are allowed to use generative AI tools to prepare their papers with explicit disclosure on how the generative AI tools are used in the Acknowledgement section. Generative AI tools cannot be listed as an author."

**Isencao**: Edicao e gramatica sao pratica comum e estao fora do escopo da politica. Disclosure nao obrigatorio, mas recomendado.

**Responsabilidade**: Todos os coautores sao individualmente responsaveis pelo conteudo, independentemente de como foi gerado.

Fonte: [ISCA 2026 Submission Guidelines](https://www.iscaconf.org/isca2026/submit/guidelines.php)
