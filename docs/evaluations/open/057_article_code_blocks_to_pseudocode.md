## Problema

§7.2 "Metrica Fonologica Independente" (linhas 816-832) contem bloco de codigo Python literal.
Artigos cientificos usam pseudocodigo ou tabelas, nao implementacao direta.

## Acao

Duas opcoes (decidir antes de executar):

**Opcao A** — Manter codigo no ARTICLE.md como referencia interna, marcar com
nota "NAO PUBLICAR" e converter para pseudocodigo/tabela nos derivados (ICASSP, TASLP).

**Opcao B** — Converter agora no ARTICLE.md para tabela de custos articulatorios + prosa.

Nota: §4.2 (DA Loss) ja usa formato adequado (formula + tabela + prosa). Aplicar o mesmo padrao.
